# THESA Black — tournament board

Phone-first one-pager for pool play. Reuse it every event by editing `data.js`.

## Use today
Open `index.html` on a phone or laptop. Tap a match to log 2–0 / 2–1. Scores save in that browser.

Live GitHub Pages (after you enable Pages on main / root):
https://eric25nielsen.github.io/thesa-black-tournaments/

## Next tournament
1. Edit `data.js` (event name, date, court, pool, teams, match order).
2. Mark THESA Black with `us: true`.
3. Set each match `result` to `null` until played.
4. Use **Reset local scores** on the page if a phone still has last week’s taps.

Official host PDFs stay the source of truth. This page is the THESA Black view only.
